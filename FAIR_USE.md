## 1. What this project is

- An **original re-creation** of the look and feel of the classic Microsoft Office Assistant, written from scratch as HTML/CSS/JavaScript.
- **Transformative** and **educational** in purpose: it demonstrates web animation, retro UI design, and interaction patterns, and preserves a piece of computing history for study and enjoyment.
- **Non-commercial.** It is given away for free under the [PolyForm Noncommercial 1.0.0](LICENSE) license. Nothing here is sold, and the license forbids commercial use.
- It **contains no Microsoft assets.** The Office Assistant sprite images, animations, and sounds are **not stored in this repository**. They are loaded at runtime from a third-party CDN (the [clippy.js](https://github.com/smore-inc/clippy.js) project). This repo ships only the author's own code.

## 2. Copyright — Fair Use (17 U.S.C. § 107)

U.S. copyright law lists four factors courts weigh in a fair-use analysis. This project is offered in good-faith reliance on them:

1. **Purpose and character of the use.** Non-commercial, educational, and nostalgic; free to all; no revenue, ads, or paywalls. Non-commercial and transformative uses weigh toward fair use.
2. **Nature of the copyrighted work.** The Office Assistant is a creative work, which generally weighs against fair use — acknowledged here honestly. This project does not claim otherwise; it leans on the other three factors and on not copying the work itself.
3. **Amount and substantiality used.** This repository copies **none** of the protected artwork, animation data, or sound. It provides only original code that *references* assets hosted elsewhere. The portion of Microsoft's work reproduced *in this repo* is effectively zero.
4. **Effect on the market.** This project has **no** effect on any market for the Office Assistant. Microsoft does not sell Clippy; there is no product this substitutes for or competes with, and it is free and non-commercial.

## 3. Trademark — Nominative Fair Use

"Clippy" and "Clippit" are trademarks/associated with Microsoft. This project uses those names **only to identify and refer to Microsoft's character** — the accurate, descriptive way to say what the project re-creates. Under the nominative-fair-use doctrine:

1. The character **cannot be readily identified** without using its name;
2. **Only as much of the name is used as is reasonably necessary** to identify it; and
3. Nothing here **suggests sponsorship or endorsement** by Microsoft — the opposite is stated prominently (see [NOTICE.md](NOTICE.md)).

The names are used descriptively and in good faith, never to imply an official or authorized product.
